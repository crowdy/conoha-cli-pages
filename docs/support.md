# 構築サポート（無料）

ConoHa 上での **HPC・GPU・k8s・大規模インフラ** の設計／構築／トラブルシュートを、**conoha-cli を作った本人** が無料でお手伝いします。

## なぜ無料なのか

conoha-cli の **OSS 活動** です。料金はいただきません。道具を実戦で鍛え、事例を増やすことが目的です。

## 対象

- 実際に ConoHa を使っている、または検討している方
- 特に **Slurm / GPU クラスター / k8s / 大規模計算基盤** のような、一人で立ち上げるのが難しいインフラ

（ConoHa と関係のない作業や、単純な代行のみのご依頼はお受けできません。）

## 進め方

1. 下記から相談内容を送る（GitHub Discussions）
2. 一緒に conoha-cli で構築する（設計・実行・確認）
3. 差し支えなければ、事例として記録・公開させてください

## お願いする前提

- 無償・ベストエフォートです（SLA はありません）
- 事例公開は事前にご相談します
